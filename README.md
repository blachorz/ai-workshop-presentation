# 跨部門 AI 分享會 (AI Workshop Presentation)

這是一個關於「無痛登入 AI 時代：從科技名詞到我們的工作語言」的跨部門分享會簡報。
本專案使用純 HTML/CSS/JS 打造，無須安裝任何複雜的套件，即可在瀏覽器中呈現流暢的簡報與多媒體互動體驗。

## 🌟 線上觀看

👉 **[點此觀看線上簡報](https://blachorz.github.io/ai-workshop-presentation/)**

## 🚀 內容亮點

- **認知升級**：看懂 AI 進化邏輯，學會給「上下文 (Context)」比鑽研「話術 (Prompt)」更重要。
- **抑制幻覺的工作流**：介紹「零幻覺」資料處理法，透過 NotebookLM 與 FACT 法則快速榨乾萬字外電。
- **提示工程實戰封裝**：展示 Google AI Studio 如何一秒轉出乾淨 API，並提供隨點即用的專屬 Gemini Gem。

## 💻 本地端執行

1. 將本專案 Clone 到本地端：
   ```bash
   git clone https://github.com/blachorz/ai-workshop-presentation.git
   ```
2. 進入資料夾後，直接用任何現代瀏覽器（Chrome, Edge, Safari 等）開啟 `index.html` 即可觀看。

## 🛠 操作方式

- **下一頁**：按鍵盤 `➡️` (右方向鍵)、`Space` (空白鍵)、`Enter` 或點擊畫面**右半部**。
- **上一頁**：按鍵盤 `⬅️` (左方向鍵) 或點擊畫面**左半部**。
- **多媒體互動**：簡報內的圖片、PDF 與影片皆可點擊彈出觀看（支援全螢幕與縮放）。

## 📂 專案結構

- `index.html`: 簡報主程式（包含樣式與互動邏輯）
- `*.png`: 簡報所需的圖表與範例圖片
- `*.pdf`: 鉅亨場景應用參考文件
- `*.mp4`: 無程式碼 AI 團隊整合示範影片
